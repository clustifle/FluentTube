# FluentTube icon

An original blue layered play tile. The rear tile suggests another video frame; the white play mark stays clear at taskbar sizes. It does not use the YouTube badge or Microsoft logos.

FluentTube.svg is the editable color master. FluentTube-monochrome.svg is a currentColor variant for monochrome placements. IconPreview.png shows illustrative light/dark placements, not app screenshots. PNG assets include future Store logo sizes; no Store submission or MSIX package is implied.

Rebuild with `python scripts/Generate-Icons.py` on Windows with Pillow installed. The generator uses the same geometric coordinates for SVG and supersampled PNG/ICO output. Windows ICO sizes: 16, 24, 32, 48, 64, 128, and 256 pixels. Standard interface controls continue using Segoe Fluent Icons.
