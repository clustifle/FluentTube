# FluentTube 1.0 RC1

A Windows 11 x64 release candidate for the native WinUI 3/Mica client. This is an unsigned portable build; .NET and Windows App SDK runtimes are included.

## Included

- Original layered blue play icon in the executable, taskbar, and native title bar; editable vector masters and Windows asset sizes.
- Home, channels, local subscriptions, Watch later, history, and Google Takeout CSV/ZIP import.
- Native playback and available H.264/AAC quality up to 1080p, including portrait Shorts.
- Fullscreen, aspect-aware compact PiP with minimize, captions, seeking, playback speed, and queue controls.
- One fresh-stream recovery attempt on eligible remote playback failures, with position/play-state restoration where Windows reports them.
- Versioned portable ZIP, SHA-256 checksum, installation guide, privacy information, component notices, and release checklist.

## Install

Extract the entire Windows ZIP and open FluentTube.exe. Keep Assets and Tools beside the executable. Close older versions first. Local data remains in %LOCALAPPDATA%\FluentTube.

## Known limits and release gates

Automated logic checks and local Windows media-engine checks passed, including public video, two distinct Shorts pages, portrait 1080p, seeking, and speed changes. The embedded executable icon and portable ZIP/checksum were inspected. These checks do not establish that all full-window interactions work.

Clean-machine launch, interactive fullscreen/PiP restore, accessibility, and multi-monitor verification are still required before stable release. This draft is not the stable v1.0 release.

YouTube may throttle or restrict unofficial public access. No Google account sync, personalized feed, comments, or upload tools are included. Captions and supported codecs depend on the source and Windows. ARM64 and signed MSIX distribution remain outside this release.
